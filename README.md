StrukturDataTree
=================

Implementasi sederhana struktur data Tree untuk sistem parkir.

Isi:

- `ParkingTree.java` — kode utama (kelas `ParkingTree`, metode `main`, operasi tree untuk sistem parkir, dll.)
- `ParkingNode.java` — definisi node (atribut kendaraan, referensi anak/kiri-kanan, dll.)

Catatan: dibuat semata-mata untuk tujuan pembelajaran. Silakan gunakan, modifikasi, dan pelajari kodenya, dan jangan ragu menghapus atau mengubah bagian yang membantu proses belajar anda.
